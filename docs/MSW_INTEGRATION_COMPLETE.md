## 🎮 How to Use

### Enable API Mocking

In `apps/web/.env`:
```env
VITE_API_MOCKING_ENABLED=true
```

### Start Development Server

```bash
cd apps/web
bun run dev
```

**Expected Console Output:**
```
[MSW] Mocking enabled - API requests will be intercepted
```

### Disable API Mocking

Set in `.env`:
```env
VITE_API_MOCKING_ENABLED=false
```

Or remove/comment out the variable.

## 🔍 Debugging

### Check MSW Status

Look for console logs:
- `[MSW] Mocking enabled` - MSW is active
- `[MSW] POST http://localhost:3000/api/seller/register (201 Created)` - Request intercepted

### Common Issues

**MSW not starting:**
- Check `VITE_API_MOCKING_ENABLED=true` in `.env`
- Verify service worker file exists: `apps/web/public/mockServiceWorker.js`
- Clear browser cache and reload

**Requests not intercepted:**
- Check Network tab for service worker registration
- Verify MSW console logs appear
- Check handler URL matches exactly

**Handler not found:**
- Console shows: `[MSW] Warning: captured a request without a matching request handler`
- Add handler in `seller-handlers.ts`
- Check URL path and method match
