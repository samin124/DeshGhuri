  🐛 CRITICAL BUG FIX
───────────────────────────────────────────────────────────────────

Issue: "Session Error, Refresh the page" when uploading PDFs
Status: ✅ FIXED

Root Cause:
  ❌ React hook useSession() was called inside async function
  ❌ Violated React hooks rules
  ❌ Session never loaded properly
  ❌ sellerId was always null
  ❌ PDF upload failed with session error

Solution:
  ✅ Moved useSession() to component top level
  ✅ Added isPending check for loading state
  ✅ Added loading spinner during initialization
  ✅ Ensured sellerId is ready before rendering form
  ✅ Fixed type mismatches (documentType, postalCode)

Files Fixed:
  ✅ apps/web/src/routes/seller/onboarding.tsx
  ✅ apps/web/src/routes/seller/verification-status.tsx
  ✅ apps/web/src/types/seller.ts

Step 1: Add Cloudinary Credentials
  $ nano apps/server/.env
  
  Add these lines:
  CLOUDINARY_CLOUD_NAME=your_cloud_name
  CLOUDINARY_API_KEY=your_api_key
  CLOUDINARY_API_SECRET=your_api_secret
  
  Get credentials from: https://cloudinary.com

Step 2: Start Servers
  Terminal 1:  cd apps/server && bun run dev
