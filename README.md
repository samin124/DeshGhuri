# 🌍 DeshGhuri

DeshGhuri is a modern full-stack web application built using the **Better-T-Stack**, combining React, TanStack Start, Hono, Bun, PostgreSQL, and TypeScript for scalable and maintainable development.

---

## 🚀 Tech Stack

### Frontend
- React
- TanStack Start (SSR framework)
- TanStack Router
- Tailwind CSS
- shadcn/ui
- TypeScript

### Backend
- Hono
- Bun runtime
- Better-Auth authentication

### Database
- PostgreSQL
- Drizzle ORM

### Tooling
- Husky Git hooks
- Monorepo architecture
- TypeScript tooling
